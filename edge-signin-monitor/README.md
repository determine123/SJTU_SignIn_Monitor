# SJTU Canvas 签到提醒 — Edge 扩展

## 安装
1. 打开 Edge，地址栏输入 edge://extensions。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择本 README 所在的 edge-signin-monitor 文件夹（内含 manifest.json）。若下载的是 ZIP，先解压。
4. 点击工具栏“扩展”图标，找到“SJTU Canvas 签到提醒”，点击固定图标。
6. 在 Edge 中完成一次 JAccount 登录；扩展复用 Edge 自己的会话，不复用 Python 版 Chrome 的登录资料。
7. 点击“测试提醒”，确认桌面通知、循环声音能工作；点击通知按钮或扩展中的“已收到”停止声音。

## 改进
- 按明确的签到号、状态、创建时间表头提取，不再从整页随意取数字。
- 支持分离表头的表格、按创建时间选最新记录、去除重复表格记录。
- 首次发现“未签到／待签到／进行中／签到中”会提醒；初次为已签到或未知状态只建立基准。
- 号码与创建时间共同构成事件标识，基准保存在扩展本地存储，浏览器重启不重复提醒同一事件。
- 识别由页面变化触发，另有默认 30 秒后台刷新。间隔可调高，不能保证严格准时。
- Windows 桌面通知需确认，循环声音、最近 300 条日志、导出日志。
- 已登录但长时间未找到签到表格时显示异常；登录页面显示“需要登录”。
- Edge 再次启动后等待点击图标；后台工作进程休眠后恢复仍保留本次会话激活状态。

## 手机推送
只在扩展界面填写自己的 PushPlus Token、Server酱 SendKey 或 Telegram Bot Token + Chat ID。
点击保存后授权相应服务域名，再点击测试提醒。密钥只存扩展本地，不随 ZIP 发布。
每个服务只发一次请求，不保证最终送达；查看日志中的接口结果。失败不自动重试，避免重复发送。
桌面通知始终启用；声音可关闭。

## 权限说明
- https://*.sjtu.edu.cn/*：读取课程内及跨域 iframe 的签到表格；页面脚本只上报识别结果和登录状态。
- storage：设置、事件基准和日志；不启用账号同步。
- alarms：定期刷新课程。
- notifications：桌面提醒。
- offscreen：后台播放本地声音。
- 可选推送域名权限：填写服务密钥后由用户授权。
扩展不保存 JAccount 密码，不执行签到，也不绕过登录或验证码。

## 运行限制与验证范围
Edge 必须运行，电脑保持联网、不休眠。浏览器可能延迟 alarms、休眠标签或节流页面任务；不是硬实时监控。
若签到工具改域名到非 sjtu.edu.cn、改字段名或不再使用表格，目前会无法识别，需要按实际页面适配。
“已签到”不等于本次已确认上课资格；是否签到仍以课程页面为准。
已测试：在 Chrome for Testing 154 的扩展环境加载 Manifest V3 后台与弹窗；表头、数据表、分离表头、无关数字、空记录解析。
尚未测试：用户 Edge 中真实新签到产生、Windows 通知/音频实际可见可听、手机真实送达。加载后请先测试提醒。

## 与旧 Python 版的关系
两个版本各自监控，不能共用 Edge/Chrome 登录资料。建议验证扩展后停止旧版，避免两份通知。
停旧版：各命令行按 Ctrl+C。取消旧版自启动：Win+R 输入 shell:startup，移走 start-signin-monitor、start-signin-95328、start-signin-96927 三个快捷方式。
扩展须在每次 Edge 启动后点击图标启用。
Python 版也已采用同一 parser.js，持久化签到基准并提醒首次发现的活动签到；需重新启动原脚本生效。请保留扩展文件夹，因为 Python 版会读取其中的 parser.js。

原项目：https://github.com/IcekyPrime/SJTU_SignIn_Monitor
本扩展是本地改进版，未发布到 Edge 商店。

## 自动打开开关（1.0.2）
面板中的“自动打开课程页面”可独立开关，修改后点击保存并应用。关闭时不新建课程标签，已打开的课程仍受监控；开启时补齐缺失课程标签。关闭“启用监控”则停止刷新和识别提醒。关闭开关不会关闭现有标签或退出登录。

## 1.1.0：点击启用与课前提醒
每次 Edge 启动后须点击扩展图标，本次会话才监控、自动打开课程和提醒上课。暂停签到监控与上课提醒是独立开关。
面板可修改起止日期与时间；高级课表 days 为1至7，weeks 为all/odd/even，单双周 anchor 为学期第一周周一。调课请新增单日记录并调整原有日期范围，避免原日程误报。
提醒复用桌面通知、可选循环声音及已配置手机服务。必须先点击启用并保持 Edge运行；休眠/关闭期间无法保证提前30分钟送达，恢复时尚未开课可补提醒，已开课不会补报。
新版通过模拟 Chrome API 测试点击门控、浏览器重启、三次提醒时间、通知去重、非法日期、单双周与过期课程；本机 Edge 实际通知仍需点击测试验证。
更新：在 edge://extensions 中找到 SJTU Canvas 签到提醒，点重新加载，版本应为1.1.0，再点击工具栏图标。
## 移除课程提醒
课表列表的“移除课程提醒”会删除已保存课程并重新规划未来闹钟。其他课程、签到监控配置与历史记录保留。已触发的通知仍可用“已收到”停止。若另一窗口修改了课表，请重新打开面板后再移除，避免删除错误课程。

## 跨午夜与异地时区验证
课表按上海时间（UTC+8）计算。次日 00:10 上课时，提醒安排在前一天 23:40；休眠恢复时若尚未开课可补报一次，开课时及开课后不会补报。新增回归测试覆盖这些边界，并分别在洛杉矶、柏林时区执行。它们验证模拟浏览器 API 下的调度行为，不能保证电脑休眠或浏览器关闭期间实际送达。运行：node --test tests/*.test.cjs。
